  - api.replicaCount is locked to 1 (design.md §15 — SignalR state).
  - Probes are {{ .Values.api.probes.mode }} (values.yaml api.probes.mode). The
    http mode wires /alive and /health and sets HealthEndpoints__Enabled on the
    api container; tcp is the dependency-free fallback. Neither path is routed

    deploy/README.md "Install / upgrade / rollback" before relying on it.
